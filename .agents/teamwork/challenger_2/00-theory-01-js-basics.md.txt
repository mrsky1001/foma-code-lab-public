#### Проблема 1: Отсутствие объяснения условных конструкций (`if / else`) и операторов сравнения
**Тип:** `[ПРОБЕЛ]`
**Приоритет:** `Критический`
**Файл:** `content/lessons/04-js-dom/00-theory-01-js-basics.md`
**Строки:** `50-73`
**Проблема:** В теории вводятся булевы типы (`true`/`false`), но полностью отсутствует объяснение условного оператора `if / else`, логических операторов (`&&`, `||`, `!`) и строгого сравнения (`===`, `!==`). При этом практические шаги урока 04 (шаги 05, 14, 15, 16, 17, 20, 21, 23) активно используют разветвлённые условия.
**Правка:**
Добавить раздел `## Условные конструкции: if / else` между блоками «Базовые типы данных» и «Шаблонные строки»:
    ```markdown
    ## Условный оператор: if / else

    Чтобы программа принимала решения на основе данных, используется конструкция `if / else`:

    ```js
    const isOpen = true;

    if (isOpen) {
      console.log('Офис открыт для посещения');
    } else {
      console.log('Офис закрыт');
    }
    ```

    Операторы сравнения:
    - `===` — строгое равенство (проверяет значение и тип);
    - `!==` — строгое неравенство;
    - `>`, `<`, `>=`, `<=` — сравнение чисел;
    - `!значение` — логическое отрицание («НЕ»);
    - `&&` («И») и `||` («ИЛИ») — объединение условий.
    ```
