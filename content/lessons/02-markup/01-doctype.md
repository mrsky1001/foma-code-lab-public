# Тип документа и язык

Любой HTML-файл начинается с двух строк:

**1. `<!DOCTYPE html>`** — говорит браузеру: «это современный HTML5».

**2. `<html lang="ru">`** — корневой тег всего документа. Атрибут `lang` помогает поисковикам и читалкам для слабовидящих понять язык страницы.

## 🛠 Задание

В файле `index.html` замените содержимое на правильную HTML-заготовку:

1. Добавьте `<!DOCTYPE html>`
2. Откройте `<html lang="ru">`
3. Добавьте пустые теги `<head>` и `<body>`
4. Закройте `</html>`

```html:solution
<!DOCTYPE html>
<html lang="ru">
<head>
</head>
<body>
</body>
</html>
```
