# Семантические теги HTML5

В ранние годы веба разработчики строили страницы исключительно из универсальных блоков `<div>`: `<div class="header">`, `<div class="menu">`, `<div class="footer">`. 

Браузеру, поисковому роботу и скринридеру (программе чтения с экрана для незрячих пользователей) было совершенно непонятно, где на странице находится шапка, где меню, а где главный контент. Это явление назвали **«div-супом»** (div soup).

Стандарт HTML5 решил эту проблему, введя **семантические теги**.

---

## Что значит «семантический»?

**Семантика** — это значение. Семантический тег говорит браузеру и поисковикам о том, **какую смысловую роль** играет элемент на странице:

```
┌────────────────────────────────────────────────────────┐
│ <header>           Шапка сайта                         │
│   <nav>Меню навигации</nav>                            │
├───────────────────────────────────┬────────────────────┤
│ <main>                            │ <aside>            │
│   <section>                       │   Боковая панель   │
│     <h2>Каталог</h2>              │   (фильтры, баннер)│
│     <article>Карточка 1</article> │                    │
│     <article>Карточка 2</article> │                    │
│   </section>                      │                    │
│ </main>                           │                    │
├───────────────────────────────────┴────────────────────┤
│ <footer>           Подвал сайта                        │
└────────────────────────────────────────────────────────┘
```

---

## Главные семантические теги

| Тег | Назначение | Особенности |
| :--- | :--- | :--- |
| `<header>` | Шапка сайта или раздела | Содержит логотип, слоган, строку поиска или меню навигации. |
| `<nav>` | Навигация | Оборачивает основные ссылки сайта (`<ul>` и `<li>`). Не используется для мелких сервисных ссылок в тексте. |
| `<main>` | Основное содержимое | Самый важный контент страницы. **Может быть только один `<main>` на страницу!** |
| `<section>` | Логический раздел | Тематическая секция страницы (например, промо-блок Hero, секция преимуществ, секция контактов). Обязательно должна иметь свой заголовок (`h2`–`h6`). |
| `<article>` | Независимый материал | Самодостаточный блок, который имеет смысл даже в отрыве от страницы (карточка товара/офиса, статья блога, отзыв). |
| `<aside>` | Сопутствующая информация | Сайдбар, фильтры, плашки с подсказками, реклама. |
| `<footer>` | Подвал сайта | Копирайт, контакты, юридическая информация, ссылки на соцсети. |

> [!TIP]
> **Почему это критически важно:**
> 1. **SEO (Search Engine Optimization):** Поисковики (Google, Яндекс) лучше индексируют сайты с понятной семантической структурой и поднимают их выше в выдаче.
> 2. **Доступность (Accessibility / a11y):** Люди с нарушениями зрения используют скринридеры, которые позволяют по горячим клавишам мгновенно переходить к `<main>` или `<nav>`, пропуская визуальный шум.
> 3. **Читаемость кода:** Команда разработчиков сразу видит логику страницы без десятков однотипных `<div>`.

## 🛠 Задание

Замените безликие `<div>` на подходящие по смыслу семантические теги HTML5:
1. `<div class="site-header">` ➔ замените на `<header class="site-header">`
2. `<div class="site-nav">` ➔ замените на `<nav class="site-nav">`
3. `<div class="site-main">` ➔ замените на `<main class="site-main">`
4. `<div class="hero-section">` ➔ замените на `<section class="hero-section">`
5. `<div class="site-footer">` ➔ замените на `<footer class="site-footer">`

```html:start
<div class="site-header">
  <div class="site-nav">
    <a href="/">Главная</a>
    <a href="/catalog">Каталог</a>
  </div>
</div>

<div class="site-main">
  <div class="hero-section">
    <h1>Бронирование офисов</h1>
    <p>Удобные рабочие пространства</p>
  </div>
</div>

<div class="site-footer">
  <p>&copy; 2026 СмартОфис</p>
</div>
```

```html:solution
<header class="site-header">
  <nav class="site-nav">
    <a href="/">Главная</a>
    <a href="/catalog">Каталог</a>
  </nav>
</header>

<main class="site-main">
  <section class="hero-section">
    <h1>Бронирование офисов</h1>
    <p>Удобные рабочие пространства</p>
  </section>
</main>

<footer class="site-footer">
  <p>&copy; 2026 СмартОфис</p>
</footer>
```
