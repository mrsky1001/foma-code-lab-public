# Массивы объектов

Массив — это список значений. Когда нужно хранить много одинаковых по структуре объектов (например, все комнаты каталога) — используют **массив объектов**.

```js
const rooms = [                                          // квадратные скобки — это массив
  { id: 1, name: 'Мини-офис Focus',     price: 450  }, // первый элемент (индекс 0)
  { id: 2, name: 'Конференц-зал Alpha', price: 1200 }, // второй элемент (индекс 1)
  { id: 3, name: 'Опенспейс Hub',       price: 250  }  // третий элемент (индекс 2)
];
```

## Доступ к элементам

```js
rooms[0]       // первый элемент: { id: 1, name: 'Мини-офис Focus', price: 450 }
rooms[0].name  // 'Мини-офис Focus' — свойство объекта из первого элемента
rooms.length   // 3 — количество элементов в массиве
```

## Добавление и удаление

```js
rooms.push({ id: 4, name: 'VIP Suite', price: 3000 }); // добавить новый объект в конец
rooms.pop();                                             // удалить последний элемент
```

## Перебор массива

```js
rooms.forEach(room => {                                         // forEach: пройти по каждому элементу
  console.log(room.name + ': ' + room.price + ' ₽/час');      // вывести имя и цену
});
```

## 🛠 Задание

Создайте массив из 3 объектов-студентов (поля: `name`, `grade`). Переберите массив и выведите имя каждого.

```js:start
const students = [
  // Добавьте 3 студента
];

// Переберите и выведите имена
```

```js:solution
const students = [                          // массив из трёх объектов-студентов
  { name: 'Алексей', grade: 5 },           // первый студент
  { name: 'Мария',   grade: 4 },           // второй студент
  { name: 'Дмитрий', grade: 5 }            // третий студент
];

students.forEach(student => {              // перебираем каждый объект в массиве
  console.log(student.name);              // выводим поле name каждого студента
});
```
