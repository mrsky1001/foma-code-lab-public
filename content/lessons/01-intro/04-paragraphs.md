# Абзацы и форматирование текста

Заголовок у нас есть. Теперь добавим обычный текст — его разбивают на абзацы, а отдельные слова выделяют.

## Тег `<p>` — абзац

Для создания абзацев используется тег `<p>` (от *Paragraph*). Каждый `<p>` — это отдельный блок текста с отступами сверху и снизу:

```html
<!-- Тег <p> создаёт абзац с отступами сверху и снизу -->
<p>Это первый абзац текста.</p>
<!-- Второй параграф автоматически начинается с новой строки -->
<p>А это уже второй абзац.</p>
```


## Теги форматирования текста

```html
<strong>Жирный текст</strong>     <!-- важный текст — браузер делает жирным -->
<em>Курсивный текст</em>          <!-- акцент — браузер делает курсивом -->
<mark>Выделенный текст</mark>      <!-- подсветка как маркером -->
<code>Код в тексте</code>          <!-- моноширинный шрифт для кода -->
```

## Тег `<br>` — перенос строки

Иногда нужен перенос строки **без нового абзаца** (например, в адресе или стихах):

```html
<!-- <br> — одинарный тег, без закрывающей пары -->
<p>
  ул. Ленина, д. 10<br>
  оф. 205<br>
  г. Москва
</p>
<!-- Всё в одном <p>, но каждая строка на новой строке -->
```

**Разница:** `<p>` создаёт новый абзац с отступом, `<br>` просто переносит строку без отступа.

> **Важно:** не используйте цепочки `<br><br>` для создания отступов между блоками — для этого служат абзацы `<p>` и свойства отступов в CSS.

## 🛠 Задание

Добавьте под заголовком два абзаца. В первом используйте `<strong>` для выделения слова. Второй абзац сделайте из двух строк через `<br>`.

```html:start
<h1>СмартОфис</h1>

```

```html:solution
<h1>СмартОфис</h1>

<p>Коворкинг «СмартОфис» — это <strong>современное пространство</strong> для продуктивной работы и деловых встреч.</p>
<!-- <strong> выделяет важное слово жирным — остаётся строчным элементом внутри <p> -->

<p>
  г. Москва, ул. Ленина, д. 10<br>
  Работаем ежедневно с 8:00 до 22:00
</p>
<!-- <br> переносит строку внутри абзаца без нового <p> -->
```
