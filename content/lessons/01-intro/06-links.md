# Ссылки и атрибуты

Веб-страницы называются «Всемирной паутиной», потому что они связаны ссылками. Ссылка создаётся тегом `<a>` (от *Anchor* — якорь).

## Атрибуты тегов

Тегу часто нужны дополнительные настройки. Они называются **атрибутами** и пишутся **внутри открывающего тега**:

```html
<a href="https://ya.ru">Перейти на Яндекс</a>
<!-- href — атрибут, "https://ya.ru" — значение атрибута -->
```

## Виды ссылок

### 1. Абсолютная ссылка — на внешний сайт

```html
<a href="https://google.com">Google</a>   <!-- полный адрес с https:// -->
```

### 2. Относительная ссылка — на страницу того же сайта

```html
<a href="about.html">О нас</a>           <!-- файл в той же папке -->
<a href="pages/catalog.html">Каталог</a> <!-- файл в папке pages/ -->
```

### 3. Якорная ссылка — к элементу на этой же странице

```html
<!-- Ссылка-якорь: прокручивает страницу к элементу с id="contacts" -->
<a href="#contacts">Перейти к контактам</a>

<!-- Где-то ниже на странице: -->
<section id="contacts">
  <h2>Контакты</h2>
</section>
```

## Открыть в новой вкладке

Атрибут `target="_blank"` открывает ссылку в новой вкладке браузера:

```html
<a href="https://google.com" target="_blank">Открыть Google</a>
<!-- target="_blank" — открыть в новой вкладке -->
```

**Важно:** при использовании `target="_blank"` всегда добавляйте `rel="noopener"` для безопасности:

```html
<a href="https://google.com" target="_blank" rel="noopener">Google</a>
<!-- rel="noopener" — защита от уязвимости при открытии в новой вкладке -->
```
