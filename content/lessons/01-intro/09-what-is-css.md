# Что такое CSS?

Отлично! У нас есть HTML-структура. Но наша страница выглядит как документ из 90-х: чёрный текст на белом фоне, шрифт с засечками. Здесь на сцену выходит **CSS**.

**CSS** (Cascading Style Sheets — Каскадные таблицы стилей) — язык оформления. Если HTML — это кирпичи и бетон (структура), то CSS — это краска, обои и дизайн.

## Синтаксис CSS — анатомия правила

Каждое CSS-правило состоит из трёх частей:

```
h1         {      color    :    red      ;    }
↑               ↑    ↑    ↑    ↑        ↑
Селектор        Свойство  Двоеточие  Значение  Точка с зап.
```

- **Селектор** — выбирает какой элемент стилизовать (`h1`, `.card`, `#header`)
- **Свойство** — что именно меняем (`color`, `background`, `font-size`)
- **Значение** — на что меняем (`red`, `#007bff`, `16px`)
- **`;`** — точка с запятой обязательна после каждого значения

## Пример: стилизуем заголовок и страницу

```css
/* Комментарий в CSS — в /* */ — браузер их игнорирует */

h1 {                        /* выбрать все теги <h1> */
  color: #007bff;           /* цвет текста — синий */
  font-size: 32px;          /* размер шрифта — 32 пикселя */
}

body {                      /* выбрать тег <body> (вся страница) */
  background-color: #f5f5f5; /* цвет фона — светло-серый */
  font-family: sans-serif;   /* шрифт — системный без засечек */
  font-size: 16px;           /* базовый размер шрифта */
}
```

## Куда писать CSS?

Есть три способа (от худшего к лучшему):

| Способ | Пример | Когда |
|--------|--------|-------|
| Inline (в теге) | `<h1 style="color:red">` | Никогда в реальных проектах |
| Тег `<style>` | `<style>h1{...}</style>` | Только в учебных примерах |
| Внешний файл | `<link rel="stylesheet" href="style.css">` | **Всегда в настоящих проектах** |
