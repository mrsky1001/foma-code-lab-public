# Пишем первый тег `<h1>`

Пора переходить к практике! Самый главный элемент на любой странице — это её заголовок.

Для создания главного заголовка используется тег `<h1>` (от английского *Heading 1* — заголовок первого уровня).

Браузер видит этот тег и автоматически делает текст крупным и жирным, а поисковые системы (Яндекс, Google) понимают, о чём эта страница.

## Иерархия заголовков h1–h6

HTML предоставляет **шесть уровней** заголовков — от самого крупного к самому мелкому:

| Тег | Размер | Применение |
|-----|--------|-----------|
| `<h1>` | Самый крупный | Главный заголовок страницы — **один на всю страницу** |
| `<h2>` | Крупный | Разделы страницы |
| `<h3>` | Средний | Подразделы |
| `<h4>` | Небольшой | Подпункты |
| `<h5>` | Мелкий | Редко используется |
| `<h6>` | Самый мелкий | Очень редко |

Пример иерархии — как оглавление книги:
```html
<h1>СмартОфис — аренда переговорных</h1>   <!-- главный заголовок страницы -->
  <h2>Популярные комнаты</h2>               <!-- раздел -->
    <h3>Переговорная «Альфа»</h3>          <!-- подраздел -->
    <h3>Мини-офис «Фокус»</h3>             <!-- подраздел -->
  <h2>О нас</h2>                            <!-- другой раздел -->
```

**Важное правило:** на одной странице должен быть **только один** `<h1>`. Это влияет на позицию в поисковых системах.

## Как написать тег

1. Пишем открывающий тег `<h1>`.
2. Внутри пишем текст заголовка.
3. Закрываем тег `</h1>`.

```html
<h1>Привет, мир!</h1>
```
