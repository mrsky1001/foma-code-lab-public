# Списки в HTML: `<ul>` и `<ol>`

Очень часто нужно перечислить элементы: пункты меню, особенности товара, шаги инструкции. Для этого в HTML есть два вида списков.

## Маркированный список `<ul>`

`<ul>` (Unordered List) — список с точечками (маркерами). Порядок пунктов не важен.

Список создаётся из **двух тегов**:
- `<ul>` — сам список (как коробка)
- `<li>` (List Item) — каждый пункт (как вещи в коробке)

```html
<!-- <ul> открывает маркированный список -->
<ul>
  <li>HTML</li>    <!-- отдельный пункт списка -->
  <li>CSS</li>     <!-- следующий пункт -->
  <li>JavaScript</li>
</ul>
```

Браузер отобразит это как:
- HTML
- CSS
- JavaScript

## Нумерованный список `<ol>`

`<ol>` (Ordered List) — список с нумерацией. Используйте когда **порядок важен**: шаги рецепта, инструкции, рейтинги.

```html
<!-- <ol> открывает нумерованный список -->
<ol>
  <li>Открыть редактор кода</li>   <!-- будет пронумерован как 1. -->
  <li>Написать HTML</li>           <!-- будет пронумерован как 2. -->
  <li>Открыть в браузере</li>      <!-- будет пронумерован как 3. -->
</ol>
```

Браузер отобразит:
1. Открыть редактор кода
2. Написать HTML
3. Открыть в браузере

## Когда что использовать

| Тег | Когда использовать | Пример |
|-----|-------------------|--------|
| `<ul>` | Порядок НЕ важен | Список технологий, пункты меню |
| `<ol>` | Порядок ВАЖЕН | Инструкции, шаги, рейтинги |

## Важная деталь: вложенность

Теги `<li>` должны находиться **только внутри** `<ul>` или `<ol>`. Нельзя поставить `<li>` без родительского списка.

```html
<!-- ПРАВИЛЬНО: li внутри ul -->
<ul>
  <li>Пункт</li>
</ul>

<!-- НЕПРАВИЛЬНО: li без ul -->
<li>Пункт</li>  ← браузер отобразит, но это ошибка
```

Под вашим абзацем создайте два списка:
1. `<ul>` — маркированный список из трёх технологий: HTML, CSS, JavaScript
2. `<ol>` — нумерованный список из трёх шагов изучения: «Изучить HTML», «Освоить CSS», «Написать JavaScript»

```html:start

<p>Это мой первый сайт, и я только учусь веб-разработке.</p>

<!-- Добавьте ul и ol ниже -->
```

```html:solution
<h1>Привет, мир!</h1>
<p>Это мой первый сайт, и я только учусь веб-разработке.</p>

<ul>                         <!-- маркированный список: порядок не важен -->
  <li>HTML</li>              <!-- пункт списка -->
  <li>CSS</li>               <!-- пункт списка -->
  <li>JavaScript</li>        <!-- пункт списка -->
</ul>

<ol>                         <!-- нумерованный список: порядок важен -->
  <li>Изучить HTML</li>      <!-- шаг 1 -->
  <li>Освоить CSS</li>       <!-- шаг 2 -->
  <li>Написать JavaScript</li> <!-- шаг 3 -->
</ol>
```
