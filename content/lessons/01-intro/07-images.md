# Картинки `<img>`

Для вставки изображений используется тег `<img>` (от *Image*). Это **одиночный тег** — без закрывающей пары, потому что внутрь картинки нельзя вложить другой тег.

## Обязательные атрибуты

```html
<img src="https://example.com/cat.jpg" alt="Рыжий кот">
<!--   ↑ src — Source (источник): путь или URL к картинке
                                ↑ alt — Alternative: текст если картинка не загрузится -->
```

**Зачем alt?**
- Показывается пользователю если картинка не загрузилась
- Читается программами для слабовидящих (скринридерами)
- Учитывается поисковыми системами (SEO)
- Никогда не оставляйте `alt` пустым для значимых картинок

## Размеры картинки

```html
<!-- Всегда указывайте width и height в HTML -->
<img src="photo.jpg" alt="Фото" width="300" height="200">
<!--                              ↑ ширина в пикселях   ↑ высота в пикселях -->
```

**Зачем указывать размеры в HTML?** Браузер заранее резервирует место под картинку — страница не «прыгает» когда изображение загрузится. Это важно для показателя CLS (Cumulative Layout Shift).

## Ленивая загрузка

```html
<!-- loading="lazy" — картинка загружается только когда пользователь доскроллит до неё -->
<img src="photo.jpg" alt="Фото" width="300" height="200" loading="lazy">
```

Это ускоряет начальную загрузку страницы: изображения внизу не загружаются сразу.

## Форматы изображений

| Формат | Когда использовать |
|--------|--------------------|
| **JPG/JPEG** | Фотографии. Сжатие с потерями, маленький размер файла |
| **PNG** | Скриншоты, логотипы с прозрачностью |
| **SVG** | Иконки, иллюстрации — масштабируется без потери качества |
| **WebP** | Современный формат: лучше JPG и PNG по качеству и размеру |

## Адаптивность в CSS

```css
img {
  max-width: 100%;   /* картинка никогда не выйдет за пределы контейнера */
  height: auto;      /* высота масштабируется пропорционально */
  display: block;    /* убрать пространство под картинкой (baseline gap) */
}
```

## 🛠 Задание

Добавьте логотип проекта «СмартОфис» сразу после заголовка `<h1>`. Укажите все атрибуты: src, alt, width, height и loading.

```html:start
<h1>Привет, мир!</h1>

<p>Это мой первый сайт, и я только учусь веб-разработке.</p>
```

```html:solution
<h1>Привет, мир!</h1>

<img
  src="https://placehold.co/150x50/007bff/FFF?text=SmartOffice"
  alt="Логотип СмартОфис"   <!-- alt: описание для скринридеров и SEO -->
  width="150"               <!-- width: резервирует место до загрузки -->
  height="50"               <!-- height: вместе с width предотвращает CLS -->
  loading="lazy"            <!-- loading="lazy": загрузить только когда нужно -->
>

<p>Это мой первый сайт, и я только учусь веб-разработке.</p>
```
