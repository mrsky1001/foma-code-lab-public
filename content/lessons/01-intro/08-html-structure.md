# Базовая структура HTML-документа

До сих пор мы писали теги просто подряд — браузер достаточно умён, чтобы это отобразить. Но по стандарту HTML каждый файл должен иметь строгий **каркас**, без которого поисковики и браузеры могут работать непредсказуемо.

## Концепция вложенности

HTML-теги **вкладываются друг в друга** как матрёшки. Внутри одного тега живут другие теги — это называется **дерево тегов**.

```
html                       ← корень, самый внешний
├── head                   ← "голова": настройки страницы
│   ├── meta               ← кодировка
│   └── title              ← название вкладки
└── body                   ← "тело": всё видимое
    ├── h1                 ← заголовок
    ├── p                  ← абзац
    └── ul                 ← список
        ├── li
        └── li
```

**Ключевое правило:** если тег B находится **внутри** тега A — тег A должен быть открыт ДО B и закрыт ПОСЛЕ B.

```html
<!-- ПРАВИЛЬНО: head полностью внутри html -->
<html>
  <head></head>
  <body></body>
</html>

<!-- НЕПРАВИЛЬНО: теги перекрываются -->
<html>
  <head>
</html>    ← нельзя закрывать html раньше head!
```

## Пошаговое построение структуры

Строим каркас шаг за шагом — каждый новый тег идёт **внутрь** предыдущего:

**Шаг 1** — объявление типа документа, всегда первая строка:
```html
<!DOCTYPE html>
```

**Шаг 2** — корневой тег `<html>`, в него оборачивается абсолютно всё. Атрибут `lang="ru"` говорит поисковику язык страницы:
```html
<!DOCTYPE html>
<html lang="ru">
</html>
```

**Шаг 3** — внутри `<html>` добавляем два главных блока: `<head>` (настройки) и `<body>` (содержимое):
```html
<!DOCTYPE html>
<html lang="ru">
  <head>
  </head>
  <body>
  </body>
</html>
```

**Шаг 4** — внутри `<head>` добавляем обязательные мета-теги:
```html
<head>
  <meta charset="UTF-8">          <!-- кодировка: без неё кириллица → кракозябры -->
  <title>Моя страница</title>     <!-- текст на вкладке браузера -->
</head>
```

**Шаг 5** — в `<body>` помещаем весь видимый контент:
```html
<body>
  <h1>Привет!</h1>
  <p>Мой первый сайт.</p>
</body>
```

**Итог — полный каркас:**
```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Привет!</h1>
    <p>Мой первый сайт.</p>
  </body>
</html>
```

## Правило отступов

Каждый вложенный тег сдвигается на **2 пробела** вправо относительно родителя. Это не обязательное правило языка, но важное для читаемости — сразу видно кто где вложен.

## Частые ошибки

| Ошибка | Последствие |
|--------|------------|
| Забыть `<!DOCTYPE html>` | Браузер включит режим совместимости с сайтами 2000-х |
| Не закрыть `</head>` перед `<body>` | Браузер угадает структуру сам, но не всегда правильно |
| Положить содержимое вне `<body>` | Непредсказуемое отображение в разных браузерах |

## 🛠 Задание

Напишите полный HTML-каркас **с нуля**, используя пошаговый алгоритм выше. В `<head>` добавьте кодировку и название вкладки. Внутри `<body>` напишите заголовок `<h1>Привет!</h1>`.

```html:start
<!-- Начните с <!DOCTYPE html> и стройте структуру шаг за шагом -->
```

```html:solution
<!DOCTYPE html>                          <!-- объявление: это HTML5-документ -->
<html lang="ru">                         <!-- корневой тег, lang — язык страницы -->
  <head>                                 <!-- невидимая "голова" страницы -->
    <meta charset="UTF-8">              <!-- кодировка: поддержка кириллицы -->
    <title>Моя страница</title>         <!-- текст на вкладке браузера -->
  </head>
  <body>                                 <!-- всё видимое содержимое -->
    <h1>Привет!</h1>                    <!-- главный заголовок страницы -->
  </body>
</html>                                  <!-- закрывающий корневой тег -->
```
