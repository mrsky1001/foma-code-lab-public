# CSS-селекторы

Чтобы изменить стиль элемента, нужно сначала его «найти». Для этого используются **селекторы** — способы указать браузеру на нужный элемент.

## Три основных типа селекторов

### 1. Тег-селектор — по имени тега

Применяется ко **всем** элементам с таким тегом на странице:

```css
h1 {                    /* все теги <h1> на странице */
  color: #007bff;
}

p {                     /* все теги <p> */
  font-size: 16px;
  line-height: 1.6;
}
```

### 2. Класс-селектор — по атрибуту `class`

Применяется к **элементам с определённым классом**. Класс — многоразовый: один класс можно дать нескольким элементам.

Сначала добавляем класс в HTML через атрибут `class`:
```html
<div class="card">Карточка 1</div>
<div class="card">Карточка 2</div>  <!-- тот же класс -->
<p class="lead">Важный текст</p>
```

Потом стилизуем в CSS через `.` (точку) перед именем класса:
```css
.card {                 /* все элементы с class="card" */
  background: white;
  border-radius: 8px;
  padding: 16px;
}

.lead {                 /* все элементы с class="lead" */
  font-size: 18px;
  font-weight: 600;
}
```

### 3. ID-селектор — по атрибуту `id`

Применяется к **одному уникальному элементу**. ID должен быть уникальным на странице — нельзя давать двум элементам одинаковый id.

В HTML через атрибут `id`:
```html
<header id="main-header">Шапка сайта</header>
<nav id="main-nav">Навигация</nav>
```

В CSS через `#` перед именем:
```css
#main-header {          /* элемент с id="main-header" — только один! */
  background: #222;
  color: white;
  padding: 16px 24px;
}

#main-nav {             /* элемент с id="main-nav" */
  display: flex;
  gap: 16px;
}
```

## Сравнение селекторов

| Тип | CSS | HTML | Когда |
|-----|-----|------|-------|
| Тег | `h1 {}` | `<h1>` | Стилизовать все теги одного вида |
| Класс | `.card {}` | `class="card"` | Многоразовые компоненты |
| ID | `#header {}` | `id="header"` | Один уникальный элемент |

## Комбинирование

Можно выбирать элементы внутри других элементов:

```css
nav a {                 /* все теги <a> внутри <nav> */
  color: white;
  text-decoration: none;
}

.card h3 {              /* все <h3> внутри элементов с классом .card */
  font-size: 18px;
}
```

## 🛠 Задание

Напишите CSS для следующего HTML: стилизуйте тег `p`, класс `.highlight` и id `#title`.

```html:start
<h1 id="title">Заголовок страницы</h1>
<p>Обычный абзац текста.</p>
<p class="highlight">Выделенный абзац.</p>
<p>Ещё один обычный абзац.</p>
```

```css:start
/* 1. Стилизуйте все <p>: color: #333, font-size: 16px */
/* 2. Стилизуйте .highlight: background: #fff3cd, padding: 8px */
/* 3. Стилизуйте #title: color: #007bff, font-size: 28px */
```

```html:solution
<h1 id="title">Заголовок страницы</h1>
<p>Обычный абзац текста.</p>
<p class="highlight">Выделенный абзац.</p>
<p>Ещё один обычный абзац.</p>
```

```css:solution
p {                         /* CSS тег-селектор: все теги <p> */
  color: #333;              /* CSS свойство: тёмно-серый цвет текста */
  font-size: 16px;          /* CSS свойство: размер шрифта */
}

.highlight {                /* CSS класс-селектор: элементы с class="highlight" */
  background: #fff3cd;      /* CSS свойство: жёлтый фон выделения */
  padding: 8px;             /* CSS свойство: внутренний отступ */
  border-radius: 4px;       /* CSS свойство: скруглённые углы */
}

#title {                    /* CSS id-селектор: элемент с id="title" */
  color: #007bff;           /* CSS свойство: синий цвет заголовка */
  font-size: 28px;          /* CSS свойство: размер заголовка */
}
```
