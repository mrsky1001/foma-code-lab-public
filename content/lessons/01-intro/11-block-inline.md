# Блочные и строчные элементы

В HTML все элементы делятся на две основные категории в зависимости от того, как они ведут себя в потоке документа по умолчанию: **блочные (Block)** и **строчные (Inline)**.

Понимание этой разницы избавляет от 90% типичных проблем с отступами и шириной у начинающих верстальщиков.

---

## 1. Блочные элементы (Block)

К блочным тегам относятся: `<div>`, `<p>`, `<h1>`–`<h6>`, `<ul>`, `<li>`, `<header>`, `<main>`, `<section>`, `<footer>`.

### Особенности поведения:
- Всегда начинаются **с новой строки**;
- Занимают **всю доступную ширину** родительского контейнера (100%), даже если текста внутри всего одно слово;
- Корректно принимают любые размеры: `width`, `height`, `padding`, `margin`.

```html
<!-- Каждый абзац автоматически встанет на новую строку на всю ширину -->
<p>Первый блок</p>
<p>Второй блок</p>
```

---

## 2. Строчные элементы (Inline)

К строчным тегам относятся: `<span>`, `<a>`, `<strong>`, `<em>`, `<code>`.

### Особенности поведения:
- **Не начинаются с новой строки**, а встраиваются прямо в текстовую строку друг за другом;
- Занимают ровно столько места, сколько необходимо для их текстового содержимого;
- ⚠️ **Игнорируют свойства `width` и `height`** (им нельзя задать жёсткую ширину или высоту);
- Вертикальные внешние отступы (`margin-top`, `margin-bottom`) **не сдвигают** соседние строки.

```html
<!-- Ссылки встанут в одну строчку друг за другом -->
<a href="#">Главная</a>
<a href="#">О проекте</a>
```

---

## 3. Свойство `display: inline-block` — лучшее из двух миров

Что делать, если ссылке `<a>` нужно придать вид полноценной кнопки (задать `padding: 12px 24px`, `width` и верхние отступы), но при этом оставить её в одной строке с другими кнопками?

Для этого используется свойство **`display: inline-block`**:
- Элемент остаётся в строке (как строчный);
- Но получает возможность реагировать на `width`, `height`, `margin` и `padding` (как блочный).

```css
.btn {
  display: inline-block; /* превращаем строчную ссылку <a> в интерактивную кнопку */
  padding: 10px 20px;
  background-color: #007bff;
  color: white;
  text-decoration: none;
  border-radius: 6px;
}
```

---

## Сравнительная таблица

| Характеристика | `display: block` | `display: inline` | `display: inline-block` |
| :--- | :--- | :--- | :--- |
| **С новой строки?** | Да | Нет | Нет |
| **Ширина по умолчанию** | 100% родителя | По размеру контента | По размеру контента |
| **Поддерживает `width`/`height`** | Да | Нет (игнорирует) | Да |
| **Поддерживает `margin-top/bottom`** | Да | Нет | Да |

## 🛠 Задание

Превратите ссылки `.menu-link` в строчно-блочные элементы (`display: inline-block`), задайте им внутренние отступы `8px 16px`, фоновый цвет `#e2e8f0` и скругление углов `4px`.

```html:start
<nav>
  <a href="#" class="menu-link">Офисы</a>
  <a href="#" class="menu-link">Цены</a>
  <a href="#" class="menu-link">Контакты</a>
</nav>
```

```css:start
.menu-link {
  /* Сделайте ссылки строчно-блочными */
  /* Задайте padding: 8px 16px */
  /* Добавьте фон #e2e8f0 и скругление 4px */
}
```

```html:solution
<nav>
  <a href="#" class="menu-link">Офисы</a>
  <a href="#" class="menu-link">Цены</a>
  <a href="#" class="menu-link">Контакты</a>
</nav>
```

```css:solution
.menu-link {
  display: inline-block;
  padding: 8px 16px;
  background-color: #e2e8f0;
  border-radius: 4px;
  text-decoration: none;
  color: #1e293b;
}
```
