# Введение в веб-разработку

В этом курсе мы изучим основы создания веб-страниц и вместе разработаем полноценный сервис бронирования переговорных комнат **«СмартОфис»**.

Каждая веб-страница строится на взаимодействии трёх технологий:

## Три технологии — одна аналогия

Представьте человека:
- **HTML** — это скелет и органы. Задаёт структуру: заголовки, параграфы, изображения, ссылки, формы.
- **CSS** — это кожа, одежда и стиль. Управляет внешним видом: цвета, шрифты, отступы, анимации.
- **JavaScript** — это мышцы и нервная система. Добавляет поведение: реакции на клики, динамические данные, логику.

```html
<!-- HTML: структура -->
<button class="btn">Забронировать</button>
```
```css
/* CSS: внешний вид */
.btn { background: #007bff; color: white; padding: 10px 20px; }
```
```js
// JavaScript: поведение
btn.addEventListener('click', () => alert('Забронировано!'));
```

## Что вы построите

К концу курса у вас будет работающее веб-приложение:
- **Главная страница** с каталогом переговорных комнат
- **Страница комнаты** с деталями и формой бронирования
- **Поиск и фильтрация** по цене, вместимости, названию
- **Автоматический слайдер** с фотографиями
- **Форма с валидацией** и сохранением данных

## Как работает тренажёр

Справа от теоретического блока — редактор кода и окно предпросмотра. Написанный код отображается в реальном времени.

Порядок работы:
1. **Теория** — внимательно читайте объяснение
2. **Практика** — пишите код в редакторе по заданию
3. **Проверка** — нажмите «Проверить» (порог 80%) или «Показать решение»
4. **Далее** — кнопка активируется после выполнения задания
