# Что такое HTML?

**HTML** (HyperText Markup Language — Язык гипертекстовой разметки) — основа любой веб-страницы. Это не язык программирования, а язык **разметки**: мы помечаем фрагменты текста тегами, и браузер знает как их отображать.

## Теги — строительные блоки HTML

Тег — это специальная метка в угловых скобках. Большинство тегов имеют **открывающий** и **закрывающий** варианты:

```html
<h1>Это заголовок</h1>
<!-- открывающий тег ↑        ↑ закрывающий тег (со слэшем) -->
```

Браузер читает этот код и понимает: «текст внутри `<h1>` — главный заголовок страницы, сделать его крупным и жирным».

## Самозакрывающиеся теги

Некоторые теги не имеют закрывающей пары — им нечего содержать внутри:

```html
<img src="photo.jpg" alt="Фото">   <!-- изображение -->
<br>                                <!-- перенос строки -->
<input type="text">                 <!-- поле ввода -->
<hr>                                <!-- горизонтальная линия -->
```

## Атрибуты — настройки тегов

Атрибуты дают тегу дополнительные параметры. Они пишутся **внутри открывающего тега**:

```html
<a href="https://ya.ru" target="_blank">Яндекс</a>
<!-- ↑ тег  ↑ атрибут  ↑ значение     ↑ ещё атрибут -->
```

- `href` — адрес ссылки
- `target="_blank"` — открыть в новой вкладке
- `src` — источник изображения
- `alt` — альтернативный текст

## Что делает браузер

Вы пишете HTML-код → браузер парсит его → строит **дерево элементов (DOM)** → рендерит страницу:

```
Вы пишете:           Браузер строит:        Пользователь видит:
<h1>Привет</h1>  →   объект H1           →   крупный жирный текст
<p>Текст</p>     →   объект P            →   абзац с отступами
<img src="...">  →   объект IMG          →   картинка
```
