# ES-модули в JavaScript: import и export

В простых проектах несколько файлов скриптов подключают через обычные теги `<script src="...">` один за другим. При этом все переменные и функции попадают в **единое глобальное пространство имён** (`window`).

Если в файле `data.js` есть переменная `rooms`, и в файле `search.js` случайно объявить переменную `rooms`, произойдёт конфликт имён или трудноуловимая ошибка перезаписи.

Для решения этой проблемы современный JavaScript использует официальный стандарт **ES Modules (ECMAScript Modules)**.

---

## 1. Подключение модульного скрипта к HTML

Чтобы браузер понял, что файл использует модули, в тег `<script>` добавляется атрибут `type="module"`:

```html
<script type="module" src="js/app.js"></script>
```

> [!IMPORTANT]
> **Особенности `type="module"`:**
> 1. **Автоматический `defer`:** Модули всегда загружаются в фоновом режиме и выполняются только после полной готовности HTML-дерева;
> 2. **Изолированная область видимости:** Переменные, объявленные внутри модуля, **не видны** в глобальном объекте `window` и в других файлах, пока вы явно их не экспортируете;
> 3. **Всегда `'use strict'`:** Модули автоматически работают в строгом режиме JavaScript.

---

## 2. Экспорт (export): делимся кодом

Чтобы сделать переменную, объект или функцию доступной для других файлов, перед ней ставится ключевое слово `export`:

```js
// Файл: js/data.js

// Именованный экспорт константы:
export const ROOMS_DATA = [
  { id: 1, name: 'Фокус', price: 450 },
  { id: 2, name: 'Альфа', price: 1200 }
];

// Именованный экспорт функции:
export function formatCurrency(amount) {
  return `${amount.toLocaleString('ru-RU')} ₽`;
}
```

---

## 3. Импорт (import): получаем код

В другом файле мы импортируем только те сущности, которые нам действительно нужны:

```js
// Файл: js/app.js

// Импортируем из файла data.js (обязательно указывать расширение .js!):
import { ROOMS_DATA, formatCurrency } from './data.js';

console.log('Загружено комнат:', ROOMS_DATA.length);
console.log('Цена первой комнаты:', formatCurrency(ROOMS_DATA[0].price));
```

---

## Именованный экспорт против Экспорта по умолчанию

| Вид | В файле-источнике | При импорте | Когда использовать |
| :--- | :--- | :--- | :--- |
| **Именованный (Named)** | `export const title = '...'` | `import { title } from './...'` | Набор утилит, списки констант, несколько функций |
| **По умолчанию (Default)** | `export default function run() {}` | `import run from './...'` (без скобок) | Главный компонент файла, модуль одной задачи |

```js
// Экспорт по умолчанию:
// Файл: js/toast.js
export default function showToast(message) {
  // показ уведомления
}

// Импорт по умолчанию (можно дать любое имя):
import showToast from './toast.js';
```

## Мост в мир React, Vite и TypeScript

Именно на ES-модулях держится весь современный фронтенд:
- Во 2-м семестре и в фреймворках (React, Vue, Vite) вы будете собирать проекты из сотен отдельных модулей;
- Сборщики (Vite, Rollup) автоматически анализируют `import` и `export`, склеивая и оптимизируя код для публикации на сервере.

В коде ниже экспортируйте константу `APP_NAME` со значением `'СмартОфис'` и стрелочную функцию `calcTax(sum)`, возвращающую 20% от суммы (`sum * 0.2`).

```js:start
// 1. Экспортируйте константу APP_NAME = 'СмартОфис'

// 2. Экспортируйте функцию calcTax(sum)
```

```js:solution
// Именованный экспорт названия приложения
export const APP_NAME = 'СмартОфис';

// Именованный экспорт функции расчёта налога (НДС 20%)
export const calcTax = (sum) => sum * 0.2;
```
