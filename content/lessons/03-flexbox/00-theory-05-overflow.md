# overflow и object-fit для изображений

Изображения на сайте часто нужно вписать в контейнер строго заданного размера. Для этого используют два свойства.

## overflow: hidden

Обрезает всё, что выходит за границы блока:

```css
.img-wrap {
  width: 300px;           /* ширина контейнера — 300px */
  height: 200px;          /* высота контейнера — 200px */
  overflow: hidden;       /* обрезать содержимое, выходящее за границы */
}
```

## object-fit: cover

Масштабирует картинку, сохраняя пропорции, и заполняет весь контейнер:

```css
.card-img {
  width: 100%;            /* растянуть по ширине контейнера */
  height: 100%;           /* растянуть по высоте контейнера */
  object-fit: cover;      /* заполнить контейнер целиком, обрезав лишнее по краям */
  display: block;         /* убрать пустое пространство снизу (img — строчный элемент) */
}
```

| object-fit | Эффект |
|-----------|--------|
| `cover` | Заполнить, обрезать лишнее |
| `contain` | Вписать целиком, могут быть поля |
| `fill` | Растянуть (искажает пропорции) |

## 🛠 Задание

Создайте контейнер 300×200px. Внутри — картинка с object-fit: cover.

```css:start
.img-wrap {
  width: 300px;
  height: 200px;
  background: #ddd;
  /* Добавьте overflow: hidden */
}

.img {
  width: 100%;
  height: 100%;
  /* Добавьте object-fit: cover */
}
```

```css:solution
.img-wrap {
  width: 300px;           /* ширина обёртки изображения */
  height: 200px;          /* высота обёртки изображения */
  background: #ddd;       /* серый фон — виден, если картинка не загрузилась */
  overflow: hidden;       /* обрезать картинку по краям контейнера */
  border-radius: 8px;     /* скруглить углы контейнера */
}

.img {
  width: 100%;            /* картинка по всей ширине контейнера */
  height: 100%;           /* картинка по всей высоте контейнера */
  object-fit: cover;      /* заполнить контейнер, обрезав лишнее (без искажений) */
  display: block;         /* убрать пространство снизу от строчного элемента img */
}
```
