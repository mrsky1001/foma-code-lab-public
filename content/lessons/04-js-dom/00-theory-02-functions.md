# Функции: объявление, параметры и стрелочный синтаксис

**Функция** — это изолированный фрагмент кода, который решает конкретную задачу и может вызываться многократно с разными входными данными. Это главный строительный блок любого веб-приложения.

---

## Анатомия обычной функции (Function Declaration)

```js
// Объявление функции
function calculatePrice(pricePerHour, hours) {
  // pricePerHour и hours — параметры (локальные переменные функции)
  const total = pricePerHour * hours;
  return total; // return возвращает результат наружу
}

// Вызов функции
const order1 = calculatePrice(800, 3); // 800 и 3 — аргументы (реальные значения)
console.log(order1); // → 2400
```

> [!IMPORTANT]
> **Оператор `return` выполняет две вещи:**
> 1. Немедленно завершает выполнение функции;
> 2. Передаёт вычисленный результат в точку вызова.
> Если `return` не указан или после него ничего нет, функция всегда возвращает `undefined`.

## Стрелочные функции (Arrow Functions)

В современном стандарте JavaScript (ES6+) для краткости активно используются **стрелочные функции**:

```js
// Полная запись со стрелкой:
const calculateTotal = (rate, hours) => {
  return rate * hours;
};

// Сокращённая запись (однострочная):
// Если тело функции состоит из одного выражения, фигурные скобки и return опускаются:
const multiply = (a, b) => a * b;

console.log(multiply(5, 10)); // → 50
```

### Сравнение синтаксиса:

| Синтаксис | Пример | Когда применять |
| :--- | :--- | :--- |
| **Function Declaration** | `function getName() { ... }` | Основные именованные функции модуля, инициализаторы |
| **Arrow Function** | `const getName = () => ...` | Компактные утилиты, вычисления, коллбэки обработчиков |

---

## Функции как аргументы (коллбэки)

В JavaScript функции являются «гражданами первого класса» (First-class Citizens). Это означает, что функцию можно:
- Записать в переменную;
- Передать как аргумент в другую функцию (такая функция называется **callback**);
- Вернуть из другой функции.

Именно на коллбэках строятся все клики и таймеры:

```js
// Передаём стрелочную функцию как аргумент в слушатель клика:
button.addEventListener('click', () => {
  console.log('Пользователь нажал на кнопку!');
});
```

## 🛠 Задание

1. Напишите функцию `calcCost(price, hours)`, которая возвращает произведение цены на количество часов.
2. Напишите однострочную стрелочную функцию `formatBadge(name, count)`, которая возвращает строку вида: `[name]: count комнат`.
3. Вызовите обе функции с тестовыми данными и выведите результаты в консоль через `console.log`.

```js:start
// 1. Напишите функцию calcCost(price, hours)

// 2. Напишите стрелочную функцию formatBadge(name, count)

// 3. Вызовите их и выведите результаты
```

```js:solution
// 1. Обычная функция для расчёта стоимости
function calcCost(price, hours) {
  return price * hours;
}

// 2. Стрелочная функция с неявным возвратом
const formatBadge = (name, count) => `${name}: ${count} комнат`;

// 3. Проверка работы
const total = calcCost(1200, 4);
const badge = formatBadge('Премиум', 3);

console.log('Итоговая стоимость:', total); // 4800
console.log('Бейдж:', badge);              // Премиум: 3 комнат
```
