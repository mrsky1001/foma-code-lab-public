# Что такое JavaScript?

HTML — скелет страницы. CSS — внешний вид. JavaScript — **поведение и логика**.

JS позволяет:
- Реагировать на клики и другие действия пользователя
- Менять содержимое страницы без перезагрузки
- Отправлять и получать данные с сервера
- Сохранять данные в браузере

## Как подключить JavaScript?

```html
<!-- В конце body или с атрибутом defer -->
<script src="js/main.js" defer></script>
<!-- defer — скрипт загружается параллельно, запускается после готовности HTML -->
```

Атрибут `defer` — скрипт загружается параллельно, но запускается после загрузки HTML.

## Типы данных

JavaScript работает с несколькими типами данных:

```js
// Строка (string) — текст в кавычках
const name = 'Студент';          // одинарные кавычки
const title = "СмартОфис";       // двойные кавычки
const message = `Привет, ${name}!`; // обратные кавычки (шаблон)

// Число (number) — целые и дробные
const age = 25;                  // целое число
const price = 800.50;            // дробное число

// Булево (boolean) — только true или false
const isLoggedIn = true;         // пользователь вошёл
const isAvailable = false;       // комната недоступна

// null — намеренное отсутствие значения
const user = null;               // пользователь ещё не загружен

// undefined — переменная объявлена, но не задана
let result;                      // result === undefined
```

## Переменные: const и let

```js
// const — постоянная: нельзя переприсвоить другое значение
const siteName = 'СмартОфис';
// siteName = 'Другое'; ← Ошибка! Нельзя переприсвоить

// let — переменная: можно изменить позже
let count = 0;
count = count + 1; // ← OK, это разрешено

// var — устаревший способ, не используйте в новом коде
var old = 'не используйте var';
```

**Правило:** используйте `const` по умолчанию. Переключайтесь на `let` только если нужно переприсваивать значение.

## Функции

```js
// Объявление функции
function greet(who) {           // who — параметр (имя входящего значения)
  return 'Привет, ' + who + '!'; // return — вернуть результат
}

// Вызов функции
const result = greet('Студент'); // передаём аргумент 'Студент'
console.log(result);             // → 'Привет, Студент!'

// Стрелочная функция (современный синтаксис)
const double = (n) => n * 2;    // короче, без return для однострочных
console.log(double(5));          // → 10
```

## Вывод в консоль

```js
console.log('Обычное сообщение');     // вывод в консоль браузера (F12 → Console)
console.error('Ошибка!');             // красное сообщение об ошибке
console.table([{ name: 'Alpha', price: 800 }]); // вывести массив/объект как таблицу
```

## 🛠 Задание

Создайте три переменные разных типов (string, number, boolean) и функцию `describe`, которая принимает имя и возвращает строку «Привет, [имя]!». Вызовите функцию и выведите результат в консоль.

```js:start
// 1. Объявите три переменные: name (string), age (number), isStudent (boolean)

// 2. Напишите функцию describe(name)

// 3. Вызовите и выведите через console.log
```

```js:solution
// Переменные разных типов
const name = 'Студент';          // string — строка
const age = 20;                  // number — число
const isStudent = true;          // boolean — булево значение

// Функция — принимает имя, возвращает приветствие
function describe(name) {
  return 'Привет, ' + name + '!'; // склеиваем строки через +
}

console.log(describe(name));     // → 'Привет, Студент!'
console.log(age);                // → 20
console.log(isStudent);          // → true
```
