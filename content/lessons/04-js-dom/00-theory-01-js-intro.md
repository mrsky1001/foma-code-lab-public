# Что такое JavaScript?

HTML — скелет страницы. CSS — внешний вид. JavaScript — **поведение и логика**.

JS позволяет:
- Реагировать на клики и другие действия пользователя
- Менять содержимое страницы без перезагрузки
- Отправлять и получать данные с сервера
- Сохранять данные в браузере

## Как подключить JavaScript?

```html
<!-- В конце body или с атрибутом defer -->
<script src="js/main.js" defer></script>
<!-- defer — скрипт загружается параллельно, запускается после готовности HTML -->
```

Атрибут `defer` — скрипт загружается параллельно, но запускается после загрузки HTML.

## Первый код

```js
console.log('Привет из JavaScript!'); // вывод в консоль браузера (F12 → Console)

// Переменные
const name = 'Студент'; // const — постоянная, нельзя переприсвоить
let count = 0;          // let — переменная, можно изменить позже

// Функция
function greet(who) {   // объявление функции, принимает параметр who
  return 'Привет, ' + who + '!'; // возвращает строку
}

console.log(greet(name)); // вызов функции → 'Привет, Студент!'
```

## 🛠 Задание

Создайте функцию `sayHello`, которая принимает имя и возвращает строку «Привет, [имя]!». Вызовите её и выведите в консоль.

```js:start
// Напишите функцию sayHello

```

```js:solution
function sayHello(name) {          // функция принимает имя как параметр
  return 'Привет, ' + name + '!'; // склеивает строки и возвращает результат
}

console.log(sayHello('Студент')); // → 'Привет, Студент!'
console.log(sayHello('Мир'));     // → 'Привет, Мир!'
```
