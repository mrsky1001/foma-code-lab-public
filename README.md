# Foma Code Lab 🚀

> Интерактивный веб-тренажёр по фронтенд-разработке и верстке (HTML, CSS, JavaScript).

🌐 **Онлайн-версия:** [https://mrsky1001.github.io/foma-code-lab-public/](https://mrsky1001.github.io/foma-code-lab-public/)

Онлайн-платформа для пошагового обучения студентов созданию реального проекта **«СмартОфис»** — сервиса бронирования офисных комнат и переговорных пространств.

## ✨ Особенности

- 💻 **Интерактивный редактор кода** на базе CodeMirror 6 с подсветкой синтаксиса, автодополнением и Emmet.
- 🔄 **Мгновенный предпросмотр (Live Preview)** в изолированном песочнице-iframe с перехватом консольных логов и ошибок.
- 📑 **10 пошаговых вебинаров/модулей**:
  1. Введение и базовый HTML
  2. Разметка страниц и блоков
  3. Flexbox и сеточные макеты
  4. JavaScript и работа с DOM
  5. Каталог и динамические карточки офисов
  6. Формы авторизации и регистрации
  7. Интерактивный слайдер
  8. Поиск и фильтрация комнат
  9. Финальная сборка и страница бронирований
  10. Диагностика и исправление ошибок
- 🔍 **Умный диффер решений**: подсветка изменений между исходным кодом и эталоном.
- 📱 **Адаптивный интерфейс**: поддержка мобильных устройств, планшетов и десктопов с изменяемыми размерами панелей (resizers).
- 💾 **Автономность**: клиентская сборка без backend-сервера — работает на любом статическом хостинге (GitHub Pages, Vercel, Netlify).

## 🛠️ Стек технологий

- **React 19** + **TypeScript**
- **Vite 8**
- **CodeMirror 6** (HTML, CSS, JS)
- **Lucide Icons**

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Продакшн сборка
npm run build

# Локальный предпросмотр продакшн сборки
npm run preview

# Тестирование статичной сборки для хостинга
npm run test:static
```
